# Portal estudiantil UNAB

Proyecto de la clase de UI. HTML, CSS y JavaScript (sin frameworks)

## Estado del proyecto

Proyecto de interfaz estática para la clase de UI. No incluye servidor ni autenticación real.

Completado:

- Páginas de creación de usuario, calculadora de notas, eventos y edición de perfil.
- Ventana de notas del horario con cierre accesible y descarga del comprobante.
- Navegación entre las páginas principales del portal.

La creación de usuario es una demostración: no crea una cuenta ni guarda contraseñas. Los cambios del perfil se guardan únicamente en el almacenamiento local del navegador.
